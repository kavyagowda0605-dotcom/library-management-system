# Book Library Management System

A full-stack web application for managing library books and users.

## Features
- User Registration & Authentication (Sign Up / Login)
- Book Management (CRUD: Add, Edit, Delete books)
- Status Toggling (Available / Issued)
- Real-time Search by title or author

## Tech Stack
- **Frontend**: React, Vite, CSS
- **Backend**: Node.js, Express.js
- **Database**: NeDB / MongoDB
